# Tip Calculator

## Overview
This is a simple tip calculator that allows users to input their bill amount and select a tip percentage to calculate the tip and total amount.

## Usage
1. Enter the bill amount in the input field.
2. Select a tip percentage from the dropdown.
3. The calculated tip and total amount will be displayed below.

## Features
- Input validation for bill amount.
- Responsive design for mobile devices.

## Edge Cases
- Negative bill amounts will not calculate a tip.
- Selecting a tip percentage without entering a bill amount will not display a calculated tip.
