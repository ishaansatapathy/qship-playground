# Add a simple dark-mode landing page with live clock

> Feature ID: `c6429401-d7e5-446c-b7e9-4732d2890fd9`

## Request

Build a single static demo page for qship-playground sandbox.

- index.html — dark background, centered layout
- Live clock (HH:MM:SS) updating every second
- Dark/Light toggle, preference in localStorage
- subtitle: "Qship playground — sandbox only"
- styles.css + app.js only (no React, no npm build)

Non-goals: React, npm build, backend, auth, multiple pages.

## Goals

- Enable users to toggle between dark and light modes with a single click.
- Increase user engagement by 30% as measured by time spent on the landing page.
- Reduce eye strain complaints by 50% based on user feedback surveys post-launch.
- Ensure the live clock updates every second without noticeable lag.

## Acceptance Criteria

- [ ] Given the landing page is loaded, when I toggle the dark/light mode, then the background and text colors should change accordingly.
- [ ] Given the landing page is loaded, when I check localStorage, then my theme preference should be saved and retrieved correctly.
- [ ] Given the landing page is loaded, when I observe the live clock, then it should update every second without delay.
- [ ] Given the landing page is loaded, when I view the subtitle, then it should display 'Qship playground — sandbox only' clearly.
- [ ] Given the landing page is loaded, when I resize the browser window, then the layout should remain centered and visually appealing.
- [ ] Given the landing page is loaded, when I inspect the page source, then only index.html, styles.css, and app.js should be present.

## Edge Cases

- If localStorage is unavailable, the page should default to dark mode.
- If the user rapidly toggles between modes, the clock should continue updating without interruption.
- If the page is loaded in a browser that does not support JavaScript, a message should indicate that the page requires JavaScript to function.
- If the user clears localStorage, the theme should revert to the default dark mode.
